# Security Policy

Open Reality View is research software. It is not intended to operate a vehicle or to be used in any safety-critical system.

To report a vulnerability, for example in data loading, checkpoint deserialization or the CI configuration, use GitHub's private vulnerability reporting (**Security → Report a vulnerability** on this repository). Please do not open a public issue. We aim to acknowledge reports within 7 days.

Only the latest `main` branch is supported.
